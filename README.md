# Magento Content Engine — Lawsons Group 5-Brand Amasty Studio

A dedicated Multi-Store Magento 2 (Amasty Blog Pro) Content Creation, Brand Multiplier, and Publishing Engine designed with a bright **Apple Liquid Glass** UI.

## Supported Magento 2 Store Views
1. **Lawsons** (`https://www.lawsons.co.uk` • `lawsons_en`)
2. **AVS Fencing & Landscaping Supplies** (`https://www.avsfencing.co.uk` • `avs_en`)
3. **Oxford Fencing Supplies** (`https://www.oxfordfencing.co.uk` • `oxford_en`)
4. **Witham Timber** (`https://www.withamtimber.co.uk` • `witham_en`)
5. **The Landscape Centre** (`https://the-landscape-centre.co.uk` • `landscape_en`)

## Core Features
- **AI 5-Brand Multiplier:** Converts 1 master blog concept into 5 unique, SEO-distinct store view variations with brand-specific internal links, tones, and CTAs so Google never flags duplicate content across the 5 websites.
- **PageBuilder-Safe Custom HTML + Scoped CSS:** Bypasses Magento PageBuilder's duplicate mobile/desktop image rendering bug and broken native product widgets by generating self-contained HTML + top `<style>` blocks tailored to each brand's exact color palette.
- **Authentic Live Storefront Previews:** Preview how any blog post looks inside the live website header & footer of Lawsons, AVS Fencing, Oxford Fencing, Witham Timber, and The Landscape Centre.
- **3 Publishing Pathways:**
  1. **1-Click Store View Scope Copier:** Copy Title, URL Key, Short Summary, Meta Tags, and Custom HTML per brand to paste into Magento Admin's Store View switcher.
  2. **Amasty Blog Pro Multi-Store CSV Export:** RFC-4180 compliant CSV export across all 5 store views.
  3. **Magento 2 REST API Direct Relay:** Serverless proxy (`/api/magento-proxy`) ready for Magento Integration Bearer Token automation.
